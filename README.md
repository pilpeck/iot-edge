# IoT Edge Platform

An extensible Raspberry Pi based IoT Edge platform.

## Architecture

Device
→ Driver
→ Connector
→ Transport

### Connectors

- Bluetooth
- WiFi
- MQTT

### Drivers

- Flymo EasiLife GO 500
- Future device types

### Goals

- Local operation
- Remote administration
- Generic device framework
- Telemetry and command routing
